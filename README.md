## ✨ Giới thiệu

Repo này là nơi mình rèn luyện **tư duy giải thuật** và cách tổ chức dữ liệu tối ưu. Đây không chỉ là lưu trữ bài tập, mà là quá trình mình học cách viết code sao cho "chạy nhanh hơn" và "tốn ít bộ nhớ hơn".

✅ Implement cấu trúc dữ liệu — ✅ Phân tích độ phức tạp Big O — ✅ Giải quyết bài toán thực tế — ✅ Tối ưu hóa code

> "Bad programmers worry about the code. Good programmers worry about data structures and their relationships." — Linus Torvalds.

---

## 🎯 Mục tiêu
- Thành thạo các cấu trúc dữ liệu cơ bản: Linked List, Stack, Queue, Tree, Graph.
- Hiểu và áp dụng các thuật toán tìm kiếm (Search) và sắp xếp (Sort).
- Rèn luyện kỹ năng phân tích độ phức tạp thời gian ($O(n)$) và không gian.
- Ứng dụng kỹ thuật Đệ quy, Chia để trị (Divide and Conquer), và Quy hoạch động.

## 🚀 Danh mục bài tập & Giải thuật

- 📂 **Basic:** Array, String, Struct.
- 📂 **Sorting:** Bubble Sort, Quick Sort, Merge Sort, Heap Sort.
- 📂 **Linear Data Structures:** Danh sách liên kết đơn/đôi, Ngăn xếp, Hàng đợi.
- 📂 **Trees:** Cây nhị phân tìm kiếm (BST), Cây AVL.
- 📂 **Graphs:** Duyệt BFS, DFS, Thuật toán tìm đường đi ngắn nhất (Dijkstra).
